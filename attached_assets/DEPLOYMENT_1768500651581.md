# NutriCoach v5 Deployment Guide

## Prerequisites
- Python 3.8+
- Supabase Account (URL and Keys)
- Gemini Cloud API Key
- SMTP Credentials (optional, for email OTP)

## Local Setup

1.  **Install Dependencies**
    ```bash
    pip install -r requirements.txt
    ```

2.  **Environment Setup**
    - The `.env` file should be present in this directory with the following keys:
      ```
      SUPABASE_URL=your_supabase_url
      SUPABASE_KEY=your_supabase_anon_key
      SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
      GEMINI_API_KEY=your_gemini_api_key
      SECRET_KEY=random_secret_string
      # Optional for Email
      SMTP_HOST=smtp.gmail.com
      SMTP_PORT=587
      SMTP_USERNAME=your_email
      SMTP_PASSWORD=your_app_password
      ```

3.  **Database Setup**
    - Go to your Supabase Dashboard -> SQL Editor.
    - Copy the contents of `setup.sql` and run it to create tables and policies.

4.  **Run Application**
    ```bash
    python app.py
    ```
    - Access at `http://localhost:5000`

## Live Deployment (Render.com)

1.  **Create New Web Service**
    - Connect your repository.
    - Choose Python environment.
    - Build Command: `pip install -r requirements.txt`
    - Start Command: `gunicorn app:app`

2.  **Environment Variables**
    - Add all variables from `.env` to the Render Environment Variables section.

3.  **Deploy**
    - Click Create Web Service.
