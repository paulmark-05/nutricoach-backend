### 1. Extract Package
```bash

```

### 2. Install & Configure
```bash
pip install -r requirements.txt

```

### 3. Setup Database & Run
```bash

```

## 📝 Configuration Required

You need these credentials (all free):

### 1. Supabase (2 min)
- Create project at [supabase.com](https://supabase.com)
- Get: URL, anon key, service key
- Run `setup.sql` in SQL Editor

### 2. Google Gemini (1 min)
- Get API key at [ai.google.dev](https://ai.google.dev)
- Free tier: 60/min, 1500/day

### 3. Gmail SMTP (2 min)
- Enable 2FA on Gmail
- Generate App Password
- Use in SMTP settings

**Full setup guide:** Read `QUICKSTART.md` or `DEPLOYMENT.md`

## 🐛 Troubleshooting

**Issue: OTP not received**
- Check spam folder
- Verify SMTP credentials
- OTPs logged to console in dev mode

**Issue: Database error**
- Run `setup.sql` in Supabase
- Verify Supabase URL and keys
- Check RLS policies

**Issue: AI not working**
- Verify Gemini API key
- Check quota limits
- Review error logs

**Full troubleshooting:** See `DEPLOYMENT.md` Section 🐛
